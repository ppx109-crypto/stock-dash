# GPT 이미지 생성 → 깃허브 올리기 시험(블로그 자동화 준비)

- 목적: 블로그 작업에서 "클로드 초안 → GPT가 이미지 지시문을 읽고 그림 생성"을 깃허브 PR만으로 이을 수 있는지 확인합니다.
- 주식 연구와는 관계없는 시험입니다. 결과를 확인하면 이 PR은 닫습니다.

## 이미지 지시문
따뜻한 아침 햇살이 드는 부엌 식탁 위에 김이 나는 커피 한 잔과 열린 노트북, 옆에 작은 화분. 부드러운 수채화 일러스트 느낌, 사람 없음, 글자 없음, 가로 16:9.

## GPT에게 부탁(순서대로 해 보고 된 것 · 안 된 것을 적어 주세요)
1. 위 지시문으로 그림을 한 장 만듭니다.
2. 그 그림 파일을 **이 PR의 가지(claude/gpt-image-test)에 `blog-test/image-test.png`로 커밋**해 봅니다.
3. 2가 안 되면, 그림을 **이 PR 댓글에 붙여** 봅니다.
4. 둘 다 안 되면, 무엇이 막혔는지(그림 생성 · 파일 올리기 · 댓글 첨부 중) 댓글로 알려 주세요.
