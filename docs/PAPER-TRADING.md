# 1시간봉 A그룹 · 한투 모의투자 자동 매매 (사용자 결정 2026-10-01 '가')

## 하는 일
- 장중 1시간봉 알림(hourly_a.py · 작업 'Hourly A group live')이 '이 봉 시가에 체결'로 정한 매수 · 매도를 **한국투자증권 모의투자 계좌에 시장가로 똑같이 주문**합니다(paper_trade.py).
- 실행 시각(평일, 한국 시각): **09:01**(전날 마지막 봉 · 일봉 정배열 깨짐으로 정한 매도) · 10:01 · 11:01 · 12:01 · 13:01 · 14:01 · 15:31(15:31은 판단만, 주문은 다음 날 09:01).
- 산 금액 = 모의 계좌 총액(예수금 + 평가금) × 칸 / 10(한 종목 최대 4칸 = 40%) · 현금 안에서만. 팔 때 다 팔리면 잔고 전부, 절반 익절이면 잔고의 반.
- 같은 매매는 두 번 주문하지 않음(hourly-live/paper-orders.json 장부의 열쇠). 디스코드 알림에 🧪 줄로 주문 결과가 붙음.

## 안전 장치
- 주문은 **모의투자 서버(openapivts.koreainvestment.com)에만** — 주문 직전에 주소를 다시 확인하고 실전 주소면 거부. 실전 계좌로는 주문하지 않음.
- 모의투자 키가 실전 키와 같으면 거부. 계좌번호 · 키 · 증권사 응답 본문은 어디에도 찍지 않음(장부에도 계좌번호 없음).
- 끄기: 저장소에 `hourly-live/paper-off` 파일을 만들거나, 작업 파일의 `PAPER_TRADING`을 `'off'`로. 비밀값이 하나라도 없으면 주문 없이 알림만.

## 처음 한 번 해 주실 일(사용자)
1. 한국투자증권 홈페이지 · 앱에서 **모의투자 신청**(국내주식 모의투자 계좌 개설).
2. KIS Developers(apiportal.koreainvestment.com)에서 **모의투자용 앱 등록** → 모의투자 App Key · App Secret 발급(실전 키와 다름).
3. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret으로 세 개를 넣기(채팅에는 쓰지 않기):
   - `KIS_PAPER_APP_KEY` — 모의투자 App Key
   - `KIS_PAPER_APP_SECRET` — 모의투자 App Secret
   - `KIS_PAPER_ACCOUNT` — 모의투자 계좌번호(예: `50123456-01` 모양, 앞 8자리-뒤 2자리)
4. 넣은 다음 날 09:01부터 자동으로 주문이 시작됨. 첫 주문 결과는 디스코드 🧪 줄과 hourly-live/paper-orders.json에서 확인.

## 2 ~ 4주 동안 볼 것
- 연구(연습 계좌) 손익과 모의 계좌 실제 체결 값의 차이(주문이 몇 분 늦는 값 · 시장가 밀림).
- 주문 거절 · 일부 체결 · 상한가 · 하한가 때의 처리.
- 차이가 작으면 실계좌 소액으로 넘어갈지 사용자와 다시 정함(실전 주문은 지금 코드에 없음).
