# 여섯 번째 갈래 RL — 전문 트레이더의 눈으로 한투 · DART 정보 쓰기(P) (사용자 2026-10-07)

사용자: "추가로 너가 전문트레이더이고 한투의 정보와 다트의 정보를 분석 활용하여 어떻게 투자할지 추가 연구해줘".
방향: 전문 트레이더가 실제로 쓰는 세 가지 — ① **사건(공시) 매매**(자사주 · 무상증자 · 실적 발표 뒤 흐름) ② **피할 것 거르기**(희석 · 나쁜 반응)
③ **위험 관리**(칸 크기 · 손절 · 국면) — 를 한투(값 · 수급 · 공매도 · 대차 · 목표가) · DART(공시 · 실적)로 재고, 지금 1일봉 규칙에 더하거나 따로 굴릴 것을 찾음.

## 잣대
- 사건 단계: 공시 날 t0(접수일) · 반응 = t0 종가까지 · **사기 = t0+1 종가** · 뒤 5 · 20 · 60일 · 그날 가운데값 뺀 초과.
  평균은 큰 종목 하나에 흔들리고 작은 종목일수록 바탕이 커져서 **'시장보다 나을 확률(바탕 50%)'과 중앙값**을 주로 봄 · 앞 반(2017 ~ 21) · 뒤 반(2022 ~ 26) 모두 같은 쪽이어야.
- 규칙 단계: 1일봉 엔진 잣대(두 반 · 씨앗 8 · 행운뺌 · 큰2건뺌 · 비용) · 따로 굴리면 계좌 연 · 골 · 1일봉과 상관 · 자르기 시험.
- 채택(모의투자)은 사용자 결정.

## 할 일 줄(P) — 회차마다 위에서 꺼냄(타이머: 이 세션 Routine '전문 트레이더 RL 회차' · 매시 52분)
| 차례 | 할 일 | 상태 |
|---|---|---|
| P1 | DART 공시 20갈래 × 발표 날 반응(오름 · 보통 · 내림) 뒤 5 · 20 · 60일 | 끝(z011) |
| P2 | P1 좋은 쪽(무상증자 · 자사주 취득 · 시설투자+내림)을 **시총 200위 안**만 · 비용 0.5% · 해마다 · 겹침 없이 다시(진짜 사고팔 수 있는 크기인가) | 끝(z012) — 큰 종목 · 비용 뒤엔 대부분 사라짐 · 무상증자만 약하게 남음 |
| P3 | P1 나쁜 쪽(자사주 처분 · 전환사채 · 유상증자 · 잠정실적 · 최대주주 변경 — 반응 내림)을 1일봉 엔진 **거르기**로(최근 20 · 60일 안) | 끝(z015) — 다섯 모두 앞 반이 나빠짐 → 버림('넷 20일'은 뒤 반 +3.4 · 지켜봄) |
| P4 | 사건 바구니 따로 굴리기: 자사주 취득 + 무상증자를 t0+1에 5칸 · 20일 → 계좌 연 · 골 · 1일봉과 상관 · 반반 계좌 | 대기 |
| P5 | 실적 발표 뒤 흐름(PEAD) 세게: 잠정실적 반응 × 분기 영업이익 놀람(작년 같은 분기 대비)이 같은 쪽일 때 | 대기 |
| P6 | 증권사 목표가 고침의 '넓이'(여러 증권사가 함께 올림/내림) → 뒤 20 · 60일 | 대기 |
| P7 | 공매도 · 대차: 대차 잔고 급감(상환) · 공매도 비중 급락 뒤 되오름(숏커버) | 대기 |
| P8 | 위험 관리: 변동성에 맞춘 칸 크기 · 국면(폭 · 지수)별 칸 줄이기를 1일봉 규칙에 | 대기 |
| P9 | 살아남은 것들을 한 장의 '전문가 운영표'로: 무엇을 사고 · 피하고 · 얼마나 · 언제 파는지 | 대기 |
