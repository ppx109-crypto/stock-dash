# 세 갈래 RL — 15분봉 · 1시간봉 · 1일봉 (사용자 2026-10-02)

사용자: "이제 연구를 15m, 1h, 1일봉 3개 RL로 진행해줘 각 각 최고의 규칙을 찾아줘. 서로 호환관계 있는지 점검도 해줘"

## 운영 방식
- 한 회차에 **세 갈래를 한 칸씩 동시에** 돌림(research/qqueue.sh 3칸 = 15분봉 · 1시간봉 · 1일봉 한 개씩). 도는 동안 다음 실험을 씀. 45분 뒤엔 새로 띄우지 않음.
- 기록: 15분봉 → docs/RL-15M-LOG.md · 1시간봉 → docs/RL-1H-LOG.md · 1일봉 → docs/RL-LOG.md · 호환 점검 → 이 문서 아래 '호환 점검'.
- 운영 중인 규칙(hourly_a · daily_live · paper_trade)은 바꾸지 않음 — 후보가 서면 사용자에게 물음.

## 모든 갈래 공통 잣대(드문 행운 막기)
두 반 모두 · 씨앗 16 · 행운뺌 · 큰2건뺌 · 비용 0.5% · 막힌/바뀐 매매 직접 · **신호(매매) 하나하나 평가** · 다른 갈래 자료로 확인(15분봉 생각은 1시간봉 긴 자료, 1시간봉 생각은 1일봉 9년 자료로 가능한 만큼).

## 호환 점검(할 것)
| 번호 | 점검 | 상태 |
|---|---|---|
| C1 | 같은 후보 문 → 세 규칙의 매매가 얼마나 겹치나(같은 종목 · 앞뒤 5거래일) | 1시간봉 ↔ 1일봉은 x001(일봉 매매의 74%가 겹침) · 15분봉 넣어 다시 |
| C2 | 주(週)마다 확정 손익의 상관 · 세 규칙을 나눠 굴릴 때 골이 얕아지나 | 할 것 |
| C3 | 한 갈래에서 찾은 개선이 다른 두 갈래에서도 통하나(옮김 표) | 15분봉 → 1시간봉: 두 거르기 긴 자료에서 짐(1시간봉 101 · 103) |
| C4 | 모의투자 한 계좌에서 두 규칙이 같은 종목을 함께 · 반대로(한쪽 사고 한쪽 팖) 주문하는 일이 얼마나 되나 | 할 것 |
| C5 | 자료 출처 호환: 같은 1시간봉 규칙이 야후 1시간봉(연구)과 한투 1분봉 모음(운영)에서 왜 다르게 나오나(1시간봉 102회차: 115.8 · 62.8 vs 68.7 · 12.4) — 운영은 한투 자료라 중요 | 할 것 |
