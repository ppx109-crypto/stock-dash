### 0-3. 용어(이 문서에서 쓰는 말)
- **t, t+1**: 판단한 날(t)과 그 다음 거래일(t+1). "t+1 종가에 산다" = 판단 다음 날 장 마감 값으로 체결.
- **초과 수익**: 그 종목 수익 − 그날 대상 종목들(시총 200위)의 **가운데값(중앙값)** 수익. 시장 전체 오르내림을 뺀 값.
  주의: 초과 수익의 **평균**은 늘 + 쪽(약 +1.5%/20일)으로 기웁니다(소수의 큰 상승 종목 때문). 그래서 **중앙값 · 이길 확률(50%가 기준) · 바탕과의 차이**를 함께 봅니다.
- **IC(정보계수)**: 그날 종목들의 '점수 순위'와 '미래 수익 순위'의 상관(스피어만). 0이면 예측력 없음. 주식 횡단면에서 **0.03 이상이면 쓸 만하고, 0.05 이상이면 강한 편**.
- **앞 반 / 뒤 반**: 학습 기간(대개 2017 ~ 2020 또는 2017 ~ 21)과 그 뒤 기간. **앞에서 고르고 뒤에서 시험**하는 것이 원칙.
- **시험 기간(OOS)**: 고를 때 한 번도 안 본 기간. 이 보고서에서는 **2023-01 ~ 2026-09**.
- **판 날 셈 vs 날마다 평가**: 매매 손익을 판 날에만 계좌에 적으면(판 날 셈) 들고 있는 동안의 평가손실이 빠져 MDD가 얕게 나옵니다. **날마다 평가**(실제 계좌처럼 종가로 매일 평가)가 정직한 값입니다.
- **PF(Profit Factor)**: 이긴 매매 이익 합 ÷ 진 매매 손실 합. 1보다 커야 하고 1.5 이상이면 좋음.
- **t값**: 매매당 평균 손익 ÷ (표준편차 ÷ √매매 수). 대략 2 이상이어야 '우연이 아닐' 가능성이 큼.
- **씨앗 폭**: 1일봉 엔진은 같은 날 후보가 여럿일 때의 작은 흔들림을 8번(씨앗 8) 다르게 돌려, 결과가 얼마나 흔들리는지(폭)를 봅니다. 이 폭보다 작은 차이는 '같음'으로 봅니다(1일봉: 앞 약 1.4%p · 뒤 약 3%p, 15분봉: 약 14%p).

### 0-5. 미래 참조를 막은 방법(가장 중요)
1. **그날까지 나온 값만**: 수급 · 공매도 · 신용 · 공시 · 실적은 모두 장 끝난 뒤 나올 수 있으므로 **t까지 자료를 보고 t+1 종가에 산다**고 셈.
2. **DART는 기준일이 아니라 접수일**: 3월 결산 숫자를 4월에 알았다고 가정하지 않음. 각 보고서의 `접수번호` 앞 8자리(=접수일) 이후에만 씀.
3. **시가총액도 그날 값**: 그날까지 접수된 주식 수 × 그날 종가로 그날 순위를 매김(오늘 시총으로 과거를 고르지 않음).
4. **순위 · 가운데값은 그날 가로줄만**: 미래 날과 섞어 문턱을 정하지 않음.
5. **자르기 시험**: 어느 날 뒤 자료를 처음부터 안 읽은 채(잘라서) 다시 돌려도, 그날 앞 판단 · 손익이 한 칸도 달라지지 않아야 통과(`research/lookahead.py`, `dguard.py` 열 겹 검사, 이번 연구 재료 묶음 z001도 통과).
6. **검사 눈**: 일부러 미래를 보는 재료(예: 내일 수급)를 넣으면 반드시 잡히는지 확인 → 검사 도구가 고장 나지 않았음을 보증.
7. **15:15 확인**: 종가에 사는 규칙은 15:15 값으로 판단해도 같은 결정인지 15분봉으로 확인.

## 1. 가장 중요한 질문의 답

> **"KIS의 시장 데이터와 DART의 기업 · 공시 데이터를 결합했을 때, 단독으로 사용할 때보다 미래 수익률을 유의미하게 예측하는 추가 정보가 실제로 존재하는가?"**

### 짧은 답
**두루 섞은 점수로는 '없다', 조건을 아주 좁힌 사건 규칙에서는 '작게 있다'.**

### 1-1. 두루 섞은 점수(횡단면 예측) — 추가 정보 없음 (`research/z040.py`)
- 방법: 5거래일마다 그날 시총 200위 종목의 **20일 뒤 초과 수익 순위**를 맞히는 모형. 재료 50여 개를 네 묶음으로 나눔.
  - KIS 가격(8): 5 · 20 · 60일 수익, 12-1 모멘텀, 52주 고점비, 20일 변동성, 정배열, 거래대금 증가
  - KIS 수급 등(23): 투자자별 20 · 60일 순매수, 외국인 전환, 프로그램, 공매도 비중 · 변화, 신용 잔고 · 변화, 대차 변화, 매수 체결 비, 증권사 의견 수 · 목표가 여력 · 목표가 올림
  - DART(19): 공시 갈래별 최근 60일 건수(17갈래), 영업이익 · 매출 전년 대비 증가(접수일 기준)
- 학습 2017-03 ~ 2020, 검증 2021 ~ 22(나무 깊이 고르기), **시험 2023 ~ 26(처음 봄)**. 모형: 선형(Ridge)과 나무(HistGradientBoosting = LightGBM과 같은 방식).

| 재료 묶음 | 선형 시험 IC (t · 95% 구간) | 나무 시험 IC (t) |
|---|---|---|
| KIS 가격만 | −0.020 (t −0.8) | −0.016 |
| KIS 전체 | +0.016 (t 1.0 · −0.003 ~ +0.034) | +0.013 (t 0.9) |
| DART만 | +0.015 (t 1.8 · +0.002 ~ +0.026) | −0.007 |
| KIS + DART 전부 | +0.013 (t 1.1) | +0.013 (t 1.2) |
| **DART를 더해 늘어난 IC**(날마다 짝지은 차이) | **−0.003 (95% −0.009 ~ +0.003)** | **+0.000 (95% −0.008 ~ +0.008)** |

→ 시험 기간에 모든 묶음의 IC가 0.01대로 **0과 통계적으로 구분되지 않고**, DART를 더해도 늘지 않습니다. 대형주 횡단면에서 '많이 섞으면 맞힌다'는 가설은 **기각**입니다.

### 1-2. 조건을 좁힌 결합 — 작게 있음
| 결합 | 무엇이 KIS, 무엇이 DART | 증거 |
|---|---|---|
| **사건 바구니 C** | DART: 자사주 취득 · 무상증자 공시 / KIS: 그날 주가 반응(−2% 아래) | 두 반 모두 플러스 · PF 1.70 / 2.01 · t 1.7 / 2.1 · 비용 1%에도 생존(§2 · §9) |
| **가치 비율**(이익 수익률 · 장부 비율) | DART: 영업이익 · 자본(접수일) / KIS: 그날 시총(가격 × 주식 수) | 보고서 접수 날 IC **+0.086(t 3.7) · 두 반 모두 +** — 그러나 **계좌로 굴리면 앞 반에 바탕보다 짐**(§3) |
| 이익의 질(영업현금 ÷ 영업이익) | DART만 | IC +0.033(t 2.4) · 두 반 모두 + · 약함 |
- '자사주를 산다'는 공시 자체는 이익이 없고(자사주 취득 전부: 연 +0.5% / −6.5%), **시장이 그 공시에 실망해 내렸을 때만** 그 뒤 20일이 좋음 → DART 사건 × KIS 반응이 함께 있어야 생기는 정보.

### 1-3. 의외의 결과 — 가장 강한 새 신호는 KIS 단독
**공매도 비중이 낮은 종목**(KIS 일별 공매도 비중 20일 평균이 낮은 순 위 20)을 달마다 사면 두 반 모두 코스피를 크게 앞섬(§2 · §3 · §9). 이것은 DART와 결합한 것이 아니라 **KIS 단독 신호**입니다.

## 6. 자동매매용 규칙 (파이썬으로 바로 옮길 수 있는 숫자 꼴)

> 모든 판단은 **판단 시각까지 나온 자료만** 씁니다. `t` = 판단하는 거래일. 수급 · 공매도 · 공시 · 목표가는 **t−1(전날)까지**만 씁니다(장 끝난 뒤 확정되므로).
> 저장소의 실제 운영 코드: `daily_live.py`(1일봉) · `basket_live.py`(바구니 C) · `idle_live.py`(빈칸 엔진 · 인버스) · `paper_trade.py`(모의 주문 · 돈 비키기).

### 6-1. 1일봉 '새 82' (운영 중 · 계좌 몫 50% · 10칸)
```python
# 입력: 일봉 종가 close[d][code], 거래량 vol, 그날 시가총액 순위 cap_rank(그날까지 접수된 주식 수 × 그날 종가)
#       투자자별 순매수 flow[kind][d][code] (kind: 'foreign','trust','individual') — 장 끝 뒤 확정 → t-1까지만
#       증권사 목표가 opinions[code] = [(report_date, target_price), ...]           — 보고서 날 다음 날부터
SLOTS = 10            # 계좌(이 봇 몫)를 10칸으로
MAX_WEIGHT = 0.40     # 한 종목 최대 40%

def sma(x, n):  return mean(x[-n:])

def market_breadth(t):                       # 시장 폭: 그날 시총 100위 중 50일선 > 200일선 비율
    top = [c for c in codes if cap_rank[t][c] <= 100]
    return mean(sma(close[:t+1, c], 50) > sma(close[:t+1, c], 200) for c in top)

def trend_door(c, t):                        # ① 추세 문
    vol20 = std(pct_change(close[t-20:t+1, c]))
    return (cap_rank[t][c] <= 100
            and pct_rank_among_top100(vol20, t) <= 0.40          # 20일 변동성이 100위 안 아래 40%
            and sma180_slope_5d(c, t) >= 0.0146                   # 180일선의 5거래일 기울기 ≥ +1.46%
            and close[t, c] / close[t-60, c] - 1 >= 0.20)         # 60거래일 전보다 +20% 이상

def aligned_door(c, t):                      # ② 정배열 문
    m = {n: sma(close[:t+1, c], n) for n in (3, 15, 20, 90, 150, 200)}
    return (cap_rank[t][c] <= 100
            and m[3] > m[15] > m[20] > m[90] > m[150] > m[200]
            and 0.19 <= m[3] / m[200] - 1 <= 0.53
            and market_breadth(t) >= 0.50)

def common_gate(c, t):                       # 공통 문: 전날까지 5거래일 합 수급 + 목표가
    f5 = lambda k: sum(flow[k][t-5:t, c])                       # t-5 … t-1 (오늘 t는 안 씀)
    if not (f5('foreign') > 0 and f5('trust') > 0 and f5('individual') < 0):
        return False
    # 목표가 줄기 = 날마다 '그날 전까지 나온 증권사 목표가들의 가운데값'(3개월 넘게 새 보고서 없으면 없음)
    now, before = target_median_before(c, t), target_median_before(c, t - 45 days)   # 달력 45일 전
    return not (now and before and now < before)                     # 45일 사이 목표가가 내렸으면 안 삼

def slots_for(c, t, door):
    if door == 'trend': return 4
    if all(flow['foreign'][d, c] > 0 and flow['trust'][d, c] > 0 for d in (t-3, t-2, t-1)): return 4
    if vol[t, c] >= 2 * median(vol[t-20:t, c]) and aligned_age_days(c, t) <= 10: return 3   # 거래량 터진 새 정배열
    return 2

def buy_list(t):                             # 15:20 판단 → 마감 동시호가(종가) 매수
    cands = [(c, 'trend') for c in codes if trend_door(c, t) and common_gate(c, t)] + \
            [(c, 'aligned') for c in codes if aligned_door(c, t) and common_gate(c, t)]
    cands.sort(key=lambda x: -sma180_slope_5d(x[0], t))         # 180일선 기울기 가파른 순
    return drop_co_moving(cands)                                 # 함께 움직이던 종목은 같이 담지 않음

def sell_rule(pos, t):                       # 종가로 판단 · 종가 매도
    r = close[t, pos.code] / pos.entry - 1
    if pos.door == 'trend':
        if r <= -0.05: return 'all'                               # 손절 −5%
        if not pos.half_done and pos.max_r >= 0.05: return 'half' # +5% 처음 닿으면 절반
        if r >= 0.13 or pos.days_held >= 10: return 'all'         # +13% 또는 10거래일
    else:
        if r <= -0.10: return 'all'                               # 손절 −10%
        if not is_aligned(pos.code, t): return 'all'              # 정배열 깨짐
        if pos.max_r >= 0.08 and r < 0.01: return 'all'           # 본전 지키기
    return None
# 비용: 왕복 0.25%(수수료 + 세금 + 작은 슬리피지). 15:15 값으로 판단해도 같은 결정인지 15분봉으로 확인됨.
```

### 6-2. 사건 바구니 C (운영 중 · 1일봉 몫의 쉬는 돈 · 5칸 / 보수형은 8칸)
```python
# 입력: DART list.json 공시(rcept_no 앞 8자리 = 접수일 d0, report_nm 제목), 일봉 종가, 그날 시총 200위
KINDS = {'자사주취득': '자기주식취득결정', '무상증자': '무상증자결정'}   # 제목 낱말로 갈래 나눔(정정 · 신탁 해지 제외)
SLOTS, HOLD, REACT_CUT, COST = 5, 20, -0.02, 0.005                       # 보수형: SLOTS = 8

def reaction(c, d0):                       # 접수일 종가 수익 − 그날 시총 200위 가운데값 수익
    r = close[d0, c] / close[d0 - 1, c] - 1
    med = median(close[d0, x] / close[d0 - 1, x] - 1 for x in top200(d0))
    return r - med

def todays_buys(t):                        # t = 접수일 다음 거래일, 15:10 판단 → 장중 시장가(종가 근처)
    out = []
    for ev in disclosures_with_date(prev_trading_day(t)):      # 어제 접수된 공시만(시각을 모르므로)
        c, kind = ev.code, ev.kind
        if c not in top200(ev.d0) or kind not in KINDS: continue
        if recently_bought(c, kind, within=20): continue        # 같은 종목 · 같은 갈래 20거래일 안 겹침 없음
        if kind == '자사주취득' and reaction(c, ev.d0) >= REACT_CUT: continue   # 시장이 실망해 내린 것만
        if held_by_other_bot(c): continue                       # 다른 봇이 든 종목은 안 삼
        out.append(c)
    return out[:free_slots()]              # 한 칸 = 이 바구니 돈 ÷ SLOTS

def sell(pos, t):  return pos.days_held >= HOLD                # 20거래일째 15:10에 팖(손절 · 익절 없음)
```

### 6-3. 공매도 비중 낮음 위 20 (연구 결과 · 운영 안 함 · 실전 검증 필요)
```python
# 입력: KIS 일별 공매도(FHPST04830000)의 공매도 거래량 비중 short_ratio[d][code] — 장 끝 뒤 → 다음 날부터
N, COST = 20, 0.005
def rebalance(t):                          # t = 그 달 첫 거래일, t의 장 끝 자료까지 보고 → t+1 종가에 체결
    score = {c: -mean(short_ratio[t-19:t+1, c]) for c in top200(t)
             if count_valid(short_ratio[t-19:t+1, c]) >= 15}  # 20일 평균(15일 이상 있어야)
    if len(score) < 50: return None
    picks = sorted(score, key=score.get, reverse=True)[:N]     # 공매도 비중이 가장 낮은 20종목
    return {c: 1 / N for c in picks}                            # 똑같이 · 다음 달 첫 거래일 다음 날까지 들기
# 위 10 · 20 · 40종목, 비용 0.5 · 1.0% 모두 두 반 + · 코스피 200일선 거르기는 오히려 나빠짐(§9)

### 6-4. 빈칸 엔진 + 코스닥 과열 인버스 (운영 중 · 규칙이 안 쓰는 돈)

def engine_on(t):  return market_breadth(t-1) < 0.50 and rule_used_share() < 0.20
def engine_pick(t):                                    # 15:10 판단, 그 주 마지막 거래일에만 다시 고름
    if ret('138230', 20) > 0.02 and close_now('069500') < sma('069500', 20):   # 하락 추세: 달러

    pos = sorted([k for k in ROT if ret(k, 20) > 0], key=lambda k: -ret(k, 20))[:2]
    return {k: 1 / len(pos) for k in pos} if pos else {}                       # 모두 −면 현금
def kosdaq_inverse(t):                                 # 엔진 돈으로 따로
    if close_now('229200') / close('229200', t-10) - 1 >= 0.095:              # 코스닥150 10일 +9.5%↑
        tp = clip(std(daily_ret('229200', 60)) * sqrt(10) * 0.25, 0.015, 0.025) # 익절 1.5 ~ 2.5%
        return dict(code='251340', stop=-0.015, take=tp, max_days=10)
# 돈 차례: 규칙(1일봉 · 15분봉) > 사건 바구니 > 엔진. 규칙이 살 돈이 모자라면 엔진을 먼저, 그다음 바구니(오래된 것부터)를 팖.
```

## 10-0. 데이터 마이닝 방법 (어떻게 찾았고 어떻게 과적합을 막았나)
1. **재료 만들기**: 모든 재료를 '그 줄 날짜 이하 자료'로만 계산(뒤로 굴리는 이동평균 · `shift(+k)`만). 묶음 z001이 자르기 시험 통과.
2. **IC 거르기**: 5거래일마다 시총 200위 횡단면 스피어만 IC(20 · 60일 뒤 초과 수익) → **앞 반 · 뒤 반 둘 다 같은 부호**인 것만 다음 단계로.
3. **계좌로 굴리기**: IC가 좋아도 실제 바구니(위 20 · 달마다 · 비용)로 굴려 바탕을 이겨야 함 — 가치(IC +0.086)는 여기서 탈락.
4. **사건 표**: 갈래(24) × 반응(오름 · 보통 · 내림) × 수급(붙음 · 보통 · 빠짐) ≈ 90칸 → 칸 하나만 좋으면 **다중검정 탓**으로 봄(90칸이면 5% 문턱에 4 ~ 5칸이 우연히 걸림). 두 반 같은 쪽 + 계좌 t + 비용 1% 생존까지 본 것만 남김(E4).
5. **머신러닝**: Ridge(선형) · HistGradientBoosting(LightGBM과 같은 방식). 학습 2017-03 ~ 2020 · 검증 2021 ~ 22(나무 깊이 등 고르기) · 시험 2023 ~ 26 한 번만 봄. 재료 중요도는 묶음 빼기(KIS만 · DART만 · 전부)로 봄(SHAP 없음).
6. **숫자 고원**: 채택 규칙의 숫자를 한 칸씩 옮겨 성적이 '봉우리'가 아니라 '고원'인지 확인(1일봉 · 바구니 C · F5).
7. **자르기 시험**: 규칙을 어느 날까지만 자료를 읽고 다시 돌려도 그날 앞 판단 · 손익이 한 칸도 안 바뀌어야 채택.

- **다중검정 보정**: 이번 연구에서 정식으로 잰 가설은 대략 사건 바구니 13 · 팩터 7 · 결합 묶음 6 · 사건 칸 90 · 투신 · 좁은 장 · 봇 강화 30여 개 ≈ 150개입니다. Bonferroni(5% ÷ 150 → t 약 3.4) 잣대를 넘는 것은 **1일봉 새 82(t 4.1)뿐**입니다. 바구니 C(t 1.7 ~ 2.1)와 F5는 "앞에서 미리 정한 뜻 있는 가설 + 두 반 같은 쪽 + 비용 생존"이라는 근거로 남겼지만, 통계만으로는 확정이 아닙니다.
- **씨앗 폭**: 1일봉은 같은 날 후보 순서의 작은 흔들림만으로 연 ±1.4%p(앞) · ±3.1%p(뒤)가 움직입니다. 이보다 작은 개선은 모두 '같음'으로 처리했습니다.
- **행운 빼기**: 1일봉 가장 큰 매매를 +30%에서 자르면 앞 +12.65% · 뒤 +18.3%(판 날 셈) — 뒤 반 수익의 상당 부분이 큰 매매 몇 건에서 옵니다.
