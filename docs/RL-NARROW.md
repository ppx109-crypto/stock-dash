# 다섯 번째 갈래 RL — 좁은 장(시장 폭 < 50%)에서도 오르는 종목(N) (사용자 2026-10-07)

사용자: "이런 과열시장 50%밑에서도 오르는 종목은 있어 그걸 너도 데이터로 확인했을거고 단타가 아니어도 좋으니 그 특징들을 찾아서 적용해보자
타이머1시간으로 RL 연구방식으로 계속 연구해줘".
까닭: 지금 세 규칙(15분봉 · 1시간봉 · 1일봉)은 시장 폭 50% 아래에서 쉼(2017 뒤 거래일의 약 45%). W 갈래(RL-WEAK)는 폭 < 50을 모두
'약세장'으로 묶어 '쉬는 게 낫다'로 끝났지만, 지금(2026-09 ~ 10)처럼 **지수는 오르는데 몇 종목만 오르는 장('좁은 오름장')**은 따로 보지 않았음.

## 목표
폭 < 50 날(특히 좁은 오름장)에 오르는 종목을 미리 고르는 규칙. 지금 1일봉 규칙이 쉬는 날을 채우는 **새 갈래** 후보.

## 잣대
- 재료 단계(N1 ~ N3): Z1과 같음(t까지 자료 · t+1 종가에 삼 · 20거래일 · 대상 = 그날 시총 200위 · 가운데값 뺀 초과 · IC · 위−아래).
  고르기 = 2017~19 · 2020~22 두 반 같은 쪽 · 시험 = 2023~26(고를 때 안 봄).
- 규칙 단계(N4 ~): 1일봉 엔진 잣대(두 반 · 씨앗 8 · 행운뺌 · 큰2건뺌 · 비용) + 1일봉 규칙과 주 손익 상관 · 함께 굴린 계좌 · 자르기 시험(dguard 방식 · research/lookahead.py).
- 국면은 그날까지 값만: 시장 폭(시총 100위 · 50일선 > 200일선) · 지수 오름(코스피 ≥ 60일선).
- 채택은 사용자 결정 · 모의투자로 넘길 때만 운영에 넣음.
