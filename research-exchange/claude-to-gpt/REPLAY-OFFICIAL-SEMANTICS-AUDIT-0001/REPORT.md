## E. 동적 호출 예산 — `dynamic-call-budget-contract.json`
- 각 요청 직전에 `used(실제 시도, 재시도 포함) + 다음 요청 수 × 3 ≤ cap`을 검사합니다. 실패하면 0회로 멈추고 `BLOCKED_CALL_BUDGET`입니다.
- DART 1단계: corpCode 1 + 종목마다 list 첫 쪽. 그 뒤 `total_page`로 남은 쪽을 하나씩 검사합니다.
- 보고서명 → 사건 표에 없는 후보가 하나라도 있으면 2단계 전에 `BLOCKED_UNMAPPED_KIND`입니다.
- 남은 허용치는 요청마다 `(cap − used) // 3`으로 다시 셉니다. **72는 예시일 뿐 고정 허용치가 아닙니다.**

| 부분 | 기본 성공 호출 | 재시도 포함 최악 |
|---|---|---|
| DART 1단계 | 1 + Σ 쪽 수(최소 34) | × 3(최소 102) |
| DART 2단계 | 고유 (종목, endpoint) + 원문 확인 사건 — 1단계 결과로만 | × 3, 남은 cap 안 |
| KIS 시세 | 1 + Σ 2 × ⌈N/100⌉ + 잘림 재조회 | × 3(전 종목 132일이면 133 → 399) |
| KIS 예탁원(선택) | API 수 × 쪽 수(tr_cont) | × 3 |
