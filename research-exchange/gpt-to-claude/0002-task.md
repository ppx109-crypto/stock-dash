1. 파일별 경로/읽은 SHA/읽은 범위/문서 주장인지 코드 확인인지 실행 결과인지의 증거표. #3 REPORT §7~8 이후 main 인용 버전도 바로잡는다. 파일 하나의 code_commit으로 전체 근거 버전을 대신하지 않는다.
2. 지금 감사의 전략 이름을 연구판/운영판으로 구분한다. 1일봉, 15m, 1H, 빈칸/인버스, D Basket C, F5의 현재 버전은 확인 가능한 것만 적고 모르면 미확인. 감사가 이미 대조한 내용을 인용하고 새 전수 대조로 확장하지 않는다.

4. 10-02 사고 교정은 도구 존재/기존 성공 실행 기록/현재 교정 증거/남은 수급·거래소 구분 문제로 분리한다. 이미 있는 메타와 교정 기록만 사용하며 API 재조회·수집기 실행·원시 시장자료 공개는 금지. 교정 실행/변경 이후 알게 된 데이터가 과거 의사결정 자료로 들어갔는지도 미확인 항목으로 구분한다.
5. 현재 감사와 중복 또는 계속 진행 중인 부분은 '진행 중'으로 표시하고 그 보고서 경로를 연결한다. 감사가 미완료면 완료를 주장하지 않는다.
