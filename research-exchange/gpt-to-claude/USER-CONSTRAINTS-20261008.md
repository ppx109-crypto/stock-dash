# 最新 사용자 조건 — 설계에 추가 반영

이 문서는 사용자 답변에 따른 조건 보완이다. 진행 중 RULES-0002를 중단·중복 실행하지 않는다. 새로운 실행 연구 단계나 추가 체인을 발행하는 문서가 아니다. 원 TASK의 코드/자료/threshold LOCK과 chain 최대3라운드는 유지한다.

## 자본 시나리오와 전환 계획
- 모의투자 검증을 완료한 뒤 실전 소액 단계로 전환할 계획이다. 실전 주문은 지금 승인되지 않았다.
- 연구 자본 시나리오: 초기 10,000,000 KRW, 향후 100,000,000 KRW.
- 소액 단계 약6개월 운용 후 증액 예정. 단순히 6개월이 지났다는 이유만으로 검증 통과 또는 자동 증액을 선언하지 않는다.
- 10배 자본은 주문 참여율·호가체결·슬리피지·concentration·capacity가 다르므로 향후 동일 규칙으로 별도 용량 검증을 요구한다. 이번 RULES-0002의 금지된 새 threshold/비용 탐색/배분 변경을 재개하지 않는다.
- 여기 적은 금액은 연구 시나리오이지 현재 실계좌 잔고나 자산 정보가 아니다.

## 위험 기준 세 가지
1. 하루 계좌 TWR 손실 기준: -15%.
2. 달력월 계좌 TWR 손실 기준: -15%.
3. 고점 대비 일별 MTM MDD 목표/허용 기준: -15% 이내.
하루·월 기준을 원금/고점 기준으로 대체하지 않는다. MDD 목표가 새로 정해졌으므로 별도 표로 평가한다. -15%보다 나쁜 관측 손실은 FAIL로 표시한다. 리스크게이트의 <=-15% 신규노출 차단 제안은 별개 상태전이다.
세 값 모두 목표와 검증 기준이며 갭·거래정지·체결불능 상황의 손실 보장은 아니다.
성과를 높이기 위해 사후 기간을 제거하거나 OOS 결과로 파라미터를 바꾸지 않는다.

## 모의투자 공개 정책 변경
사용자가 모의투자 기록은 GitHub에 올려도 괜찮다고 명시했다. 기존 문서의 '정규화 NAV도 무조건 비공개'를 아래 허용목록으로 대체한다. 이를 새 계좌 수집/API 실행 승인으로 해석하지 않는다.

공개 가능:
- 모의 여부를 검증한 paper-only 성과 요약, 일별/월별 수익률, 첫날100 정규화 NAV, MTM MDD, 현금비율, 비용·슬리피지 지표.
- 식별자를 가명화한 모의 신호·체결 대사 기록: 전략/버전, 종목, 신호·제출·체결 시각, 가격, 모의 수량, 수수료/세금, 상태, 괴리. 실제 계좌 값이 혼합되면 공개하지 않는다.
- schema/합성 fixture/비식별 파생자료. KIS/DART 원시 시장데이터 재배포는 별도 제공조건 확인 대상.

공개 금지:
- API appkey/appsecret, access/refresh token, Secret 값, 계좌번호/상품코드 결합 식별값, 원본 잔고·체결 API 응답, 원래 증권사 주문번호, 개인 식별정보, 실계좌 잔고·실계좌 NAV·실계좌 거래, 비공개 Claude 세션 URL.
- '모의'라고 써도 계좌 식별자/토큰 포함 원본 응답은 공개하지 않는다.
- Secrets를 읽어내거나 로그로 출력하지 않는다. Secret 존재/보관 방식과 연구 결과 파일 공개는 별개다.

설계:
- publish_paper_derived=true, raw_response_public=false, live_data_public=false.
- mode=paper와 대상환경을 신뢰 가능한 계좌설정/수집 provenance로 확인한 뒤 허용 필드만 생성한다.
- 비공개 원본→allowlist 변환→계좌/인증/개인정보 탐지→가명 중복체크→검토 가능한 별도 PR 순서로 설계한다. 키·원본응답을 public worktree/commit에 먼저 넣고 지우는 방식은 금지.
- 원본 비공개 보관은 아직 목적지가 정해지지 않았다. 원본을 공개 repository에 저장하지 않고 향후 수집은 필요한 최소 파생값만 보관하는 경로도 선택 가능하다.
- 이번에는 저장 정책 설계와 조건 기록만 반영한다. logger 활성화, 자동 workflow 추가, 계좌 조회, 모의주문·실주문, 운영 파일 수정은 시행하지 않는다.
