# PREREG — 합성 기업행동 원장 원자성

이 문서를 계산·코드 검색·판정 전에 커밋한다.

## 고정 fixture

- 모든 수는 `Fraction` 등 정확한 유리수로 계산한다.
- 시작 현금은 합성 고정값, 보유 종목은 합성 식별자만 사용한다.
- split 2건과 reverse_split 2건은 정수 수량으로 끝나며 비용·단주·현금보상은 0이다.
- 사건 당일의 경제적 가격 변화는 0으로 고정한다. 가격은 `m_price=1/m_qty`만큼만 기계적으로 바뀐다.
- TWR:
  - `r_t = NAV_t/NAV_{t-1}-1` (외부 현금흐름 0)
  - 달력월 TWR은 해당 일별 수익률의 기하연결
  - MDD는 일별 MTM NAV의 고점 대비 하락률
- 순수 분할·병합 ACCEPT 사례의 기대값은 일별 TWR=0, 달력월 TWR=0, MDD=0이다.

## 고정 음성대조군

- 수량만 먼저 바꾸고 가격은 다음 snapshot에서 바꾸는 부분 업데이트
- 가격에 `m_qty`를 곱하는 반대 방향
- 동일 event_key 두 번 적용
- apply_date 누락·현재 snapshot보다 과거/미래 순서 역전
- m_qty*m_price != 1
- 적용 결과 단주
- 0·음수·누락·비유한 입력

모두 성공처럼 보정하지 않는다. 부분 업데이트·반대 방향은 왜곡 크기를 보고하고, 나머지는 상태 변경 없이 차단한다.

## 채택 기준

다음을 모두 만족하면 READY다.

- 정상 4건에서 가치·현금 보존, TWR 0, 월 TWR 0, MDD 0
- 중복 적용 뒤 상태 해시가 첫 적용 뒤 상태 해시와 동일
- 음성대조군 전부 탐지
- 원장 갱신이 한 snapshot 안에서 수량·가격을 함께 바꿈
- 실제 기업행동·실제 날짜·성과에 0건 적용
- 기존 미해결 항목을 해소했다고 주장하지 않음

하나라도 실패하면 BLOCKED이며 실패 fixture와 NEEDS_DATA를 명시한다.
