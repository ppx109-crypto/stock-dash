# PREREG — 다중사건 배치 원자성 복구

계산·수정·실행 전에 커밋한다.

## 고정 상태 전이

1. 원본 상태 `S0`를 보존한다.
2. 입력 사건을 의미키 `(sym, kind, m_qty, apply_date)`로 정규화한다.
3. 같은 의미키 중복은 첫 항목만 고유 사건으로 두고 나머지는 `DUPLICATE_IGNORED`로 기록한다.
4. 각 고유 사건을 **S0 기준**으로 검증한다. 검증 중 상태를 바꾸지 않는다.
5. 실패가 하나라도 있으면 `S0`를 그대로 유지하고 배치 판정을 `BATCH_ABORTED`로 한다.
6. 전부 통과하면 scratch 상태에 적용하고 모든 불변식을 다시 확인한 뒤 한 번만 커밋한다.

## 미리 고정한 기대값

- `[A_OK, B_BAD]`와 `[B_BAD, A_OK]`: 둘 다 BATCH_ABORTED, 전체 상태 해시=S0, applied 집합 불변, PERF_BLOCKED.
- `[A_OK, B_OK]`와 역순: 둘 다 COMMITTED, 동일 최종 해시, 가치 보존.
- `[A_OK, A_DUP]`: A 정확히 한 번 적용, 중복 기록, 최종 성과 유효.
- 같은 종목의 서로 다른 두 신규 사건이 같은 날: `BLOCKED_SAME_SYMBOL_MULTI_EVENT`, 상태 불변.
- PR #104 이전 로직 음성대조군에서는 `[A_OK, B_BAD]` 뒤 A가 반영되어 결함이 재현되어야 한다.

## 채택 기준

모든 실패 배치의 상태가 byte-equivalent 해시로 보존되고, 성공 배치는 순서와 무관하게 같은 해시를 만들며, 중복 배치는 정확히 한 번만 반영될 때 READY다. 기대값을 실행 결과에 맞춰 바꾸지 않는다.
