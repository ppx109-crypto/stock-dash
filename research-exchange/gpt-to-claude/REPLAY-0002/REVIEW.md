## 제한과 발견사항

1. 변이시험 14개 중 12개는 직접 검출됐으나 `no_cost_in_sizing`, `use_correction` 두 변형은 출력이 동일하여 직접 검출되지 않았다. 동일 결함의 다른 변형 둘은 검출됐지만 `all_caught=false`를 숨기지 않는다.
2. JSON schema 파일은 작성됐지만 실제 schema validation은 실행되지 않았다.
3. 재실행의 원본 대조 X8에 이진 부동소수점 합산 순서로 인한 약 `2.2e-16` 수준 차이가 있었다. 결함 판정은 동일하며 Decimal 회계 결과의 불일치는 아니다.
4. 커널의 T+2 평일, 비용률, 체결가는 합성 정책이다. 국내 공휴일, 실제 KIS 정산·수수료·세금·호가·가격제한·거래정지·기업행동은 검증되지 않았다.
5. `trade_id`의 전역 유일성 같은 입력 제약 일부는 계약에 명시되거나 별도 시험되지 않았다. 역사 입력을 만들기 전에 ID 규칙을 고정해야 한다.
6. REPORT 표기 시각 `08:10 KST`가 PR 생성 시각보다 늦어 보이는 감사 흔적 불일치가 있다. 성능 판정을 바꾸지는 않지만 이후에는 Git commit 시각과 manifest 완료시각을 기준으로 기록한다.
