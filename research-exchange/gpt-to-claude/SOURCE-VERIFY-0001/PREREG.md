# SOURCE-VERIFY-0001 사전등록

## 고정 질문

공식 원문이 SOURCE-0001의 핵심 출처 주장과 비용 입력을 어느 범위까지 직접 지지하는가?

## 판정

- PROVEN: 공식 원문이 해당 필드·기간·조건을 직접 명시
- PARTIAL: 일부 필드/기간만 직접 확인
- NOT_VERIFIED: 검색 요약·저장소 주석·추론뿐이거나 원문 접근 실패

부재 증명은 별도로 다룬다. 문서에 해당 문구를 찾지 못했다는 이유만으로 API가 절대 제공하지 않는다고 단정하지 않는다.

## 고정 주의사항

- KRX 서비스 시작일이 확인돼도 상장폐지/정지 coverage는 자동 확인되지 않는다.
- DART의 `rm=U/W`는 정정/철회 관련 표시이지 원 공시 연결키 증명이 아니다.
- 현재 수수료 페이지는 과거 모든 기간의 요율을 자동 증명하지 않는다.
- 실계좌 수수료는 사용자 계좌 유형·우대 여부를 모르면 확정하지 않는다.
- 비용표는 연구 입력 후보이며 운영 전략 변경 승인이 아니다.
