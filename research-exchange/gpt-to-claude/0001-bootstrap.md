# 연결 시험과 현재 연구 인수인계
## 목적
양방향 문서 감지가 실제로 되는지 확인하고 현재 연구의 출발점을 보존한다.
## 허용범위
이 PR head의 공통 계약과 저장소 기존 보고서/연구 코드/문서/현재 연구 상태를 읽기. 문서 및 처리 receipt 작성.
백테스트 실행, 장시간 계산, API 데이터 신규 수집, 주문, 운영 변경은 이번 TASK 범위 밖이다.
## 할 일
1. 실제 입력 PR 번호/head SHA, 읽은 파일 경로/커밋을 기록한다.
2. 1일봉/15m/1H 빈칸엔진/코스닥 인버스/A/D/F5를 존재/정의/검증근거/미확인으로 정리한다. 현재 전략이 실전 불가라고 일괄 결론내리지 않는다.
3. 실제 확보 데이터의 기간·종목수·상장폐지 포함·available_at·누락·원천을 확인 가능한 만큼 정리한다.
4. KIS 가격/분봉/수급/공매도/호가와 DART 공시목록/원문/재무/정정 이력 중 기존에 확보된 것과 추가 확보할 것을 구분한다.
5. 기존 모의 체결 로그가 존재하는지 확인하되 계좌 원문/개인 금액은 공개하지 않는다.
6. 최초 연구 재검증에 필요한 누락 자료/질문을 목록화한다.
## 완료조건
INSTRUCTIONS의 REPORT/manifest/receipt 계약에 따라 [클로드 결과] PR 제출.
어떤 수익률도 새 실행 결과라고 주장하지 않는다. 연결 시험은 수신 PR 생성 및 GPT 검토 회신까지 확인해야 통과다.
