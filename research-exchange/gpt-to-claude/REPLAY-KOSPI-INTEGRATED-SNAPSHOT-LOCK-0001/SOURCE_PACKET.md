# SOURCE_PACKET — 고정 공식 KRX 색인 스냅샷

이 파일은 GPT가 2026-10-09 KST에 검색 색인에서 확보한 공개 발췌를 고정한다. Claude는 URL을 열지 않는다. 모든 근거 등급은 `GPT_CAPTURED_OFFICIAL_INDEX`이며 직접 원문 열람으로 승격하지 않는다.

- 공식 도메인: `law.krx.co.kr`
- URL: `https://law.krx.co.kr/las/LawBon.jsp?lawid=000111`
- 검색 결과 제목: `:::: 법규입안관리시스템 ::::`
- 색인 표시:
  - `유가증권시장 업무규정 시행세칙 [일부개정 2024.10.29 규정 제2256호 <시행일:2024.11.4>]`
  - `제1조(목적) 이 세칙은 「유가증권시장 업무규정」(이하 “규정”이라 한다)의 시행에 관하여 필요한 사항을 규정함을 목적으로 한다.`
- 검색 메타:
  - Published: 약 1.9년 전
  - Crawled: 약 2개월 전(검색 수행일 2026-10-09 기준)
- 한계:
  - Published와 Crawled는 시행일이 아니다.
  - 검색 색인 스냅샷이며 브라우저 원문 직접열람이 아니다.
  - 머리글은 같은 URL의 색인 결과에 직접 표시되었다.

## S2 — 같은 KRX 통합 URL의 제30조 제1항 제6호

- URL: S1과 동일한 `https://law.krx.co.kr/las/LawBon.jsp?lawid=000111`
- 기존 공식 색인 캡처의 정확 발췌:
  - `주식분할 또는 주식병합된 종목은 전일종가에 분할 또는 병합의 비율을 곱한 가격으로 한다.`
- 위치: `제30조(기준가격) 제1항 제6호`
- 기존 패킷·PR #96에서 파일 hash로 고정됨.
- 한계: 이번 검색 응답 한 블록에 머리글과 제30조 문장이 동시에 노출된 것은 아니지만 URL은 동일하다. 이 연결을 ACCEPT할지 REVISE할지는 사전등록 판정축대로 결정한다.

## S3 — 2022-08-26 KRX 공개본의 동일 산식

- 공식 URL: `https://law.krx.co.kr/las/RefBon.jsp?lawid=000111&lawkd=B&pubdt=20220826&pubno=0000020640`
- 위치: `제30조 제1항 제6호`
- 정확 발췌:
  - `주식분할 또는 주식병합된 종목은 전일종가에 분할 또는 병합의 비율을 곱한 가격으로 한다.`
- 한계: `pubdt`는 공개본 식별 날짜이며 단독으로 시행일이라고 간주하지 않는다.

## 독립 보조 근거

공식 KRX 법규 메인 검색 결과는 `유가증권시장 업무규정 시행...`을 현행 법규 항목으로 표시한다. 다만 lawid 직접 결합은 S1이 담당한다.
