# MEAS-0001 사전등록
1. 일차 지표는 기존 모의 측정 기록의 존재·출처, 현금/수량/NAV 대사 불일치·결손, 시점 정보 사용 위반이다. 수익률 최대값이 아니다.
2. 기간은 확인된 저장 모의 기록의 전체 공통 기간으로 잠그고 누락/불리한 날을 제외하지 않는다. 기록이 없으면 기간=null.
3. 사용 코드/hash/입력 파일/hash/평가 시각/반올림 규칙을 검사 전에 PREREG-LOCK에 기록한다. 운영 자료가 계속 변하면 읽기 전용 snapshot으로 검사한다.
4. 3개 위험 기준 −15%는 사용자 고정 기준. 자료 출처·현금·가격·비용이 검증되지 않으면 대사 후 수익률을 실측 성과로 인정하지 않는다.
5. 통계적 알파·최적 배분·새 OOS 평가/새 threshold는 미수행. 합성 fixture의 무결성/시간절단과 실제 모의 원장 대사를 분리한다.
6. 개인잔액/원본 응답을 공개하지 않는다. 모의 출처가 확인된 allowlist 파생값·가명화 기록·정규화 NAV만 공개한다.
7. 실행 budget: 기존 자료 감사와 작은 fixture만. 전체전략 백테스트/장시간 재생/수집 없음. 실패/누락은 전부 기록한다.
