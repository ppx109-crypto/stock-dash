# 현재 모의투자와 연구 측정의 신뢰성 감사

운영 변경 없이 신뢰성 등급과 증거 결손, 측정 계약 수정안을 만든다. 새 규칙 탐색/성과 재최적화는 이번 범위 밖이다.
최신 사용자 연속 연구 승인을 PROGRAM.md에서 읽고 앞선 3라운드 승인대기는 이 프로그램에 한해 대체한다.

## 감사 대상
A. 실제 모의투자 기록
- signal/intent/fill 및 비용/계좌평가 snapshot 존재 여부와 모의 출처를 구분한다. CSV/JSON이 연구 시뮬레이션인지 KIS 모의 체결인지 별도 가상체결인지 명시한다.
- 시작/종료일, 관측일수, 신호 수, 주문 의도 수, 체결 수, 부분/미체결/취소, 누락 구간, 재시작/중복, 현금/보유/가격 평가 시각을 조사한다.
- H1 몫0/PAPER off인지 현재 증거로 확인; 현재 소유한 모의 포지션과 연구 후보를 혼동하지 않는다.
- 장부가 있으면 예수금 변화=매수대금+매도대금−비용±입출금, 보유수량 변화=매수체결−매도체결±기업행사를 대사한다. 원 단위 반올림은 정산 규칙에서 정하고 임의 허용오차로 차이를 숨기지 않는다.
- NAV=현금+보유수량×가용가격−미지급비용. 입출금 TWR/일·달 손실/고점 MDD 구분.
- 거래 원문/절대 개인잔액 대신 모의 비식별 요약·정규화 NAV·차이 비율을 출력. 없는 원장을 현재 주가로 사후 생성하지 않는다.

B. 수급·공시·캐시
- 사용 정보 날짜, available_at/수신일시/확정·정정버전 기록, 의사결정 시각의 실제 정렬을 대조한다. T−2 가정이 실제 가용 증거라는 주장 금지.
- 날짜 대신 종목별 행을 shift하는 방식이 결손일/거래정지에서 시장거래일 지연과 다른지 감사한다.
- DART 접수일만 있는 이벤트는 접수 시각/장후/정정 미확인 처리. 공시 후 반응 창이 원인보다 앞서는 경우 표시.
- rule._calm/CALM_MONTH 캐시 생성 출처/기간/cutoff/calm 적용 경로 확인. cache hash 같음과 누수 없음은 별개.
- 실제 사용 캐시의 cutoff를 알 수 없으면 생성 코드의 시간절단/미래 행 추가 합성 검사로 위험을 확인하되 과거 성과 재현으로 부르지 않는다.
- 유니버스 상장폐지/정지/분할/이전/기업행사·역사 시총/수정주가 결손은 기록한다.

C. MTM·비용·체결 계약
- a_mtm의 현금·보유·부분청산·동시매수·순서·최종손익 보정이 실제 원장과 같은지 감사한다.
- 공개 진단 결과의 일별 NAV 벡터 미제출과 전체씨앗 장부 미제출을 구분한다.
- 실제 고정 비용 유효값(Z_ACC/IMPACT_K 포함), 세금 시장·날짜 적용근거, 주문액/NAV/부분청산 가정, 체결 가격·같은봉 판단 및 다음봉 진입을 확인한다.
- 1천만원/1억원 용량 시나리오가 어느 수치에 쓰였는지 확인하되 새 수익률/용량 최적화는 하지 않는다.
- 결합계좌와 D1 100% 모형을 구분한다. 동일종목·현금·슬롯 중복 여부를 측정할 증거가 없으면 검증하지 못함.

## 검증과 산출물
검토 후 부작용 없는 측정함수만 떼어 연구 경로에서 합성 검사한다. 의미 있는 합성 예: 입출금이 수익으로 잡히지 않음, 일부 청산 보유/현금 보존, 동시 진입 가용현금 제약, 미래 행 추가시 과거 판단 불변, 장후 공시 반응 시작일, 누락 수급일 cutoff.
합성 통과와 실제 모의 기록 대사를 분리한다. 운영 모듈 import/봇 실행/실제 주문 금지.
- REPORT.md: READY(감사 완료) 또는 BLOCKED(필수 실행 불가), 모의 신뢰성 결론·증거·미확인. READY가 신뢰성 PASS는 아님.
- INVENTORY.json: mode/provenance/source/path_or_alias/hash/coverage/rows/available_at_fields/missing/gaps. 비밀 값·개인 경로 식별자 제외.
- RECONCILIATION.json: 실제 관측 대사 vs 합성 검사 구분, sample_size, mismatch/missing_count, 기간, 원인. 없으면 null+이유.
- MEASUREMENT-CONTRACT.md: 현금·수량·비용·가격·TWR·MTM·수급/공시시점 계약과 원본 대비 의미 변경 제안. 운영 반영 아님.
- RELIABILITY.md: 전략별 데이터/규칙·코드/계좌·체결/OOS 각 PASS/FAIL/UNVERIFIED와 근거. 둘 중 하나라도 미검증이면 종합PASS 금지.
- TEST-RESULT.json, 실행 환경/명령/종료코드, manifest와 입력 PR+head receipt.
판정: TRUSTED_FOR_PAPER_EVALUATION / INVALID_MEASUREMENT / INSUFFICIENT_EVIDENCE. 이는 실전 채택 등급이 아니다.
자료가 없더라도 완료 가능한 결손 감사는 READY+INSUFFICIENT_EVIDENCE로 제출한다. 자료를 만들어 맞추지 않는다. 다음 과제는 GPT가 결과를 보고 한 단계로 설계한다.
