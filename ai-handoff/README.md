# GPT 설계자 ↔ 클로드 연구자 인수인계

작성: 2026-10-08 한국 시각

## 사용 목표 — 최신 사용자 조건
- 비용 이후 수익률을 높이고 계좌 낙폭을 줄인다.
- 유효한 투자 기회가 있는데 배분·슬롯·자금회수 문제로 사용하지 못한 현금을 줄인다.
- 연구 기준자본은 최초 1,000만원, 확대 검증자본은 1억원이다. 실제 계좌 잔고라는 뜻이 아니다.
- 손실 기준은 **최초 원금 대비 -15%**다. 고점 대비 MDD, 하루 손실, 한 달 손실과 별도로 계산한다.
- 추가입금으로 확대할 때 기준원금 재설정은 미확정이다. 1,000만원·1억원을 각각 독립 시나리오로 검증한다.
- 검증이 끝날 때까지 모의투자를 지속한다. 실계좌 주문 금지.
- GPT는 결과를 꼼꼼히 검토한 뒤 다음 실행 프롬프트를 작성한다.
- 기존 CLAUDE.md의 하루·월간 -15%를 최신 원금 기준의 대체 지표로 쓰지 않는다. 기존 문서를 이번 폴더 생성으로 수정하지 않았다.

## 읽는 순서
1. 이 문서
2. prompts/001-claude-handoff.md
3. reports/README.md
4. 기존 연구 문서·원장·코드와 이번 최신 연구 결과

## 역할
- 클로드: 현재 연구를 완료하고 재현 가능한 결과·한계·자료 목록을 제출한다.
- GPT: 보고서와 증거를 읽고 설계 타당성·누락·오류를 검토해 다음 지시를 작성한다.
- 사용자: 운영 변경과 실전 전환을 결정한다.
- 결과에 적힌 제안은 다음 실행 권한이 아니다. 검토 완료된 지시가 있어야 다음 새 실험으로 넘어간다.

## 회차별 기록
- GPT 지시: prompts/번호-내용.md
- 클로드 결과: reports/번호/report.md
- 실행·파일 목록: reports/번호/manifest.json
- GPT 검토: reviews/번호-review.md (검토할 때 생성)
- 기존 원자료와 큰 출력은 원래 위치에 유지하고 보고서에서 정확한 경로·커밋·해시로 연결한다.
- 최초 결과는 덮어쓰지 않는다. 수정판은 별도 파일로 이유와 차이를 남긴다.

## 전달 방식
클로드는 연구용 브랜치에서 자료를 정리해 PR을 생성한다.
PR 제목 예: 연구 인수인계 001: 결과 제출
현재 연구가 다른 브랜치에서 진행 중이면 작업을 버리거나 강제로 main으로 전환하지 않는다.
보고서에 연구 코드·데이터 기준 커밋과 제출 커밋을 구분한다.
동일 코드/자료 결과를 여러 회차에서 새로운 OOS처럼 재사용하지 않는다.

## 자동화 상태
이 폴더는 문서 인수인계 규약이다.
**폴더 생성만으로 GPT의 자동 감지 또는 클로드 자동 실행이 켜지지 않는다.**
PR 감지 자동화는 별도 설정·시험 후 사용한다.
클로드 대화창 자동 입력은 현재 연결로 검증하지 못했다.
실행 자동화를 붙일 때 중복 커밋 처리, 최신 회차, 검토 완료 여부, 최대 반복 횟수와 중단조건을 별도로 고정한다.

## 금지
비밀키·토큰·계좌번호·개인 잔고·증권사 원응답을 공개 저장소에 올리지 않는다.
모의 원장은 비식별화하고 필요하면 집계값·접근 가능한 비공개 증거 경로로 대신한다.
연구용 자본 가정과 실제 개인정보를 구분한다.
실계좌 주문, 기존 운영 설정 변경, 수익률 숫자 조작, 미확인 자료를 0으로 대체하는 행위를 금지한다.
